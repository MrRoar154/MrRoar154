## Sobre mi

Soy estudiante de **Tecnologia en Desarrollo de Software** con vision orientada a la construccion de ecosistemas tecnologicos eficientes. Mi trayectoria se define por la capacidad de entender requerimientos y convertirlos en soluciones robustas, con foco en el **desarrollo backend**, **diseno de bases de datos** y la creacion de herramientas optimizadas para entornos web y rurales.

Mi enfoque va mas alla de escribir codigo: implica entender la necesidad, disenar la solucion correcta e implementarla garantizando que el sistema sea **funcional, escalable y mantenible**. Cada proyecto que tomo involucra una seleccion adecuada del stack tecnologico basado en los fundamentos de la programacion basica, priorizando siempre la idoneidad tecnica.

Poseo experiencia trabajando con interfaces interactivas en **React y JavaScript**, hasta la construccion de sistemas backend con **Node.js, Python y Django**, y aplicaciones de escritorio con **Java y JavaFX**. Mi capacidad para gestionar infraestructura de datos con **MySQL y SQL Server**, asi como el despliegue mediante **Docker**, me permite entregar software que cumple con los objetivos de manera eficiente.

```text
Lenguajes primarios  ->  JavaScript - Python - Java
Backend              ->  Node.js - Django - Spring
Bases de datos       ->  MySQL - SQL Server
DevOps               ->  Docker
Sector rural         ->  Integracion con WhatsApp API - AppSheet
```

---

## Mi filosofia

> *"El software no es un producto final; es un sistema vivo que debe adaptarse, crecer y resistir el tiempo."*

Construyo con ese principio en mente. Cada arquitectura que diseno se sostiene sobre pilares no negociables: **confiabilidad** y **accesibilidad**. Me apasiona integrar tecnologia en sectores menos digitalizados, disenando flujos logicos que el usuario final pueda aprovechar sin fricciones.

## About Me

I'm a **Software Development Technology** student with a vision oriented toward building efficient technological ecosystems. My journey is defined by the ability to understand requirements and transform them into robust solutions, with a strong focus on **backend development**, **database design**, and the creation of optimized tools for both web and rural environments.

My approach goes beyond writing code - it means understanding the need, designing the right solution, and implementing it in a way that ensures the system is **functional, scalable, and maintainable**. Every project I take on involves a careful selection of the technology stack, always prioritizing technical suitability.

I have experience working with interactive interfaces using **React and JavaScript**, building backend systems with **Node.js, Python, and Django**, and desktop applications with **Java and JavaFX**. My ability to manage data infrastructure with **MySQL and SQL Server**, along with deployment using **Docker**, allows me to deliver software that efficiently meets its objectives.

```text
Backend            ->  Node.js - Django - Spring
Databases          ->  MySQL - SQL Server

Rural Sector       ->  WhatsApp API Integration - AppSheet
```
